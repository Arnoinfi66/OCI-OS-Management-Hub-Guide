# Product Usage Summary

## Product Used

Oracle Cloud Infrastructure OS Management Hub

## Purpose

This repository documents my product usage and understanding of OS Management Hub in Oracle Cloud Infrastructure.

## What I Created

I created a structured guide covering:

- OS Management Hub
- Oracle Cloud Agent
- Managed Instances
- Software Sources
- Patch Management Workflow
- Patch Scheduling
- Package Exclusion
- Update monitoring

## What I Practiced

I reviewed how OS Management Hub supports centralized patch management for Oracle Linux compute instances.
I also documented how software sources, managed instances, Oracle Cloud Agent, patch schedules, and package exclusions work together in the update process.

## What I Understood

My main understanding is that OS patching in OCI should be managed as a controlled process.
OS Management Hub helps administrators review updates, configure software sources, schedule patch operations, and monitor patch status from a central location.
